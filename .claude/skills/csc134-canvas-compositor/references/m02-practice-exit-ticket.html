Four things can go wrong with a program, and we use the same four words for them all term. Each question below shows you one. Pick the word that fits.

  • Syntax — you broke the grammar. The compiler cannot even read it.
  • Static semantic — the grammar is fine, the meaning is impossible. The compiler reads it, understands it, and refuses.
  • Runtime — it built and started, then fell over while running.
  • Logic — it built, ran, finished, and gave the wrong answer. Nothing complained.

There is a fast way to sort them: did it build? If no, was the compiler confused by the words or by the meaning? If yes, did it finish? If it finished, was the answer right?
